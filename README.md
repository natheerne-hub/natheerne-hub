## Featured Healthcare Data Projects

### 🏥 [Hospital Readmission Intelligence](https://github.com/natheerne-hub/Hospital-Readmissions-Healthcare-Analytics)
**Problem:** Explore hospital-level readmission performance while keeping patient-level predictive research methodologically separate.

- **Data:** CMS HRRP FY 2026 — **18,330 hospital-condition records across 3,055 hospitals and six HRRP conditions**
- **Methods:** data-quality analysis, hospital/condition/geographic comparisons, reproducible Python analytics, classification research, threshold analysis
- **Deliverables:** [Live Dashboard](https://hospital-readmissions-healthcare-an.vercel.app) · research simulator · model card · documented decision trail
- **Stack:** Python · Pandas · Scikit-learn · JavaScript · Healthcare BI
- **Principle:** hospital-level quality signals are never presented as individual patient-risk estimates

### ❤️ [Heart Disease Analysis & Risk Modeling](https://github.com/natheerne-hub/Heart-Disease-Exploratory-Data-Analysis)
**Problem:** Move from structured cardiovascular data to reproducible exploratory analysis and leakage-aware baseline modeling.

- **Data:** 918-record processed heart-disease dataset with documented upstream provenance
- **Methods:** EDA, clinical-variable visualization, train-only preprocessing, stratified hold-out evaluation, cross-validation
- **Models:** Logistic Regression and Random Forest
- **Result:** Logistic Regression hold-out **ROC-AUC 0.933** in the published analysis
- **Deliverable:** executed notebook with exported analytical figures

### 🔄 [FHIR Clinical Data Pipeline](https://github.com/natheerne-hub/fhir-clinical-data-pipeline)
Synthetic clinical interoperability project using **FHIR, HL7 v2, ICD-10-CM, LOINC, and UCUM**. Includes Patient, Condition, Observation, MedicationRequest, Encounter and Bundle resources plus an HL7-to-FHIR mapping example. All patient data are synthetic.

## Clinical + Data Perspective

My clinical background helps me approach healthcare datasets by focusing on the **clinical question, unit of analysis, data quality, interpretation, and consequences of model errors** before headline performance.

## Responsible Healthcare Analytics

- Portfolio projects are educational/research demonstrations, not medical devices.
- Predictive models require external validation, calibration, subgroup assessment, workflow evaluation, and clinical governance before real-world use.
- Dataset provenance, licensing, missingness, and unit of analysis are core analytical considerations.
