## Responsible Healthcare Analytics

- Portfolio projects are educational/research demonstrations, not medical devices.
- Predictive models require external validation, calibration, subgroup assessment, and clinical governance before real-world use.
- Dataset provenance, licensing, missingness, and unit of analysis are treated as core analytical considerations.
- Clinical usefulness matters more than headline model accuracy.
